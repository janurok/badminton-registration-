# ชั้นหนังสือ: เว็บอ่านนิยายส่วนตัว

เว็บสำหรับเผยแพร่นิยายที่เขียนเอง เน้นให้อ่านสบายตาทั้งบนมือถือและคอม เขียนนิยายเป็นไฟล์ Markdown ธรรมดาแล้วระบบสร้างหน้าเว็บให้อัตโนมัติ ไม่มี backend และไม่มีค่าใช้จ่าย

**ฝั่งคนอ่านทำอะไรได้บ้าง**

- สลับธีม อัตโนมัติ / สว่าง / ซีเปีย / มืด
- ปรับฟอนต์ (หนังสือ, อ่านง่าย, โมเดิร์น), ขนาดตัวอักษร, ระยะบรรทัด, ความกว้างหน้า และรูปแบบย่อหน้า
- จำตำแหน่งที่อ่านค้าง มีการ์ด "อ่านต่อจากที่ค้างไว้" ที่หน้าแรก
- แถบความคืบหน้า, ติ๊กตอนที่อ่านแล้ว, ป้าย "ใหม่" สำหรับตอนที่ลงภายใน 7 วัน
- เปลี่ยนตอนด้วยปุ่มลูกศร ← → บนคีย์บอร์ด

ค่าทั้งหมดเก็บไว้ในเบราว์เซอร์ของคนอ่านเอง ไม่มีระบบสมาชิก

## โครงสร้างไฟล์

```
content/                    ← ส่วนที่คุณแก้ไข
├── site.md                 ชื่อเว็บ นามปากกา คำโปรย
└── friendship-of-love/     1 โฟลเดอร์ = 1 เรื่อง (ชื่อโฟลเดอร์จะอยู่ใน URL แนะนำให้ใช้ภาษาอังกฤษ)
    ├── novel.md            ชื่อเรื่อง สถานะ แท็ก และเรื่องย่อ
    ├── cover.jpg           รูปปก (ไม่บังคับ ถ้าไม่มี ระบบจะทำปกให้)
    ├── 101.md              ภาค 1 บทที่ 1 (เลขหลักแรกคือเลขภาค)
    └── 201.md              ภาค 2 บทที่ 1
theme/                      หน้าตาเว็บ (style.css) และการทำงานฝั่งคนอ่าน (app.js)
scripts/build.mjs           ตัวแปลง content/ เป็นเว็บ
```

## เพิ่มตอนใหม่ผ่านหน้าเว็บ GitHub

1. เข้าโฟลเดอร์ของเรื่องใน `content/` แล้วกด **Add file → Create new file**
2. ตั้งชื่อไฟล์ตามลำดับตอน เช่น `206.md` (ระบบเรียงตอนตามชื่อไฟล์ และใช้เลขนี้เป็น URL ของตอน)
3. วางเนื้อหาตามรูปแบบนี้

   ```markdown
   ---
   title: ชื่อตอน
   label: บทที่ 6
   part: ภาคที่ 2 · The Present · 15 ปีต่อมา
   date: 2026-10-01
   ---
   ย่อหน้าแรก
   ย่อหน้าที่สอง
   ```

   ถ้าเรื่องไม่ได้แบ่งภาค ลบบรรทัด `label` กับ `part` ออกได้ ระบบจะนับ "ตอนที่ 1, 2, 3" ให้เอง

4. กด **Commit changes** แล้วรอประมาณ 1 ถึง 2 นาที ตอนใหม่จะขึ้นเว็บเอง

## เริ่มเรื่องใหม่

สร้างไฟล์ `content/ชื่อโฟลเดอร์ใหม่/novel.md` (พิมพ์ชื่อโฟลเดอร์ตามด้วย `/` ในช่องชื่อไฟล์ GitHub จะสร้างโฟลเดอร์ให้) แล้วใส่ข้อมูลตามตัวอย่างใน `content/friendship-of-love/novel.md`

## วิธีเขียน

| อยากได้ | พิมพ์แบบนี้ |
|---|---|
| ย่อหน้าใหม่ | ขึ้นบรรทัดใหม่ได้เลย (1 บรรทัด = 1 ย่อหน้า วางจาก Word หรือ Google Docs ได้ทันที) |
| ตัวเอียง / ตัวหนา / ขีดฆ่า | `*ข้อความ*` / `**ข้อความ**` / `~~ข้อความ~~` |
| ตัดฉาก | บรรทัดที่มีแค่ `***` |
| ข้อความในกรอบ เช่น จดหมาย ข้อความแชต | ขึ้นต้นบรรทัดด้วย `> ` |
| หัวข้อย่อยในตอน | `## หัวข้อ` |
| เส้นคั่นเปลี่ยนมุมมอง | `#### มุมมอง: วิน` |
| รูปประกอบ | `![คำบรรยายรูป](ชื่อไฟล์.jpg)` แล้วอัปโหลดรูปไว้ในโฟลเดอร์ของเรื่อง |
| ทอล์กท้ายตอน | บรรทัดที่มีแค่ `===` แล้วเขียนทอล์กต่อด้านล่าง |

## ค่าที่ตั้งได้ (ส่วนบนสุดของไฟล์ ระหว่าง `---`)

**novel.md**

| ค่า | ความหมาย |
|---|---|
| `title` | ชื่อเรื่อง |
| `subtitle` | ชื่อรอง (ไม่บังคับ) |
| `author` | ผู้เขียน ถ้าไม่ใส่จะใช้นามปากกาจาก `site.md` |
| `status` | `กำลังเขียน` / `จบแล้ว` / `พักการเขียน` |
| `tags` | แท็ก คั่นด้วยจุลภาค เช่น `แฟนตาซี, โรแมนซ์` |
| `cover` | ชื่อไฟล์รูปปก (หรือตั้งชื่อรูปว่า `cover.jpg` ไว้ในโฟลเดอร์ ระบบจะหาเอง) แนะนำสัดส่วน 2:3 กว้างราว 800 px และไฟล์ไม่เกิน 500 KB เว็บจะโหลดเร็ว |
| `color` | สีของปกที่ระบบทำให้ เช่น `"#2f4a3a"` |
| `order` | ลำดับบนหน้าแรก (เลขน้อยขึ้นก่อน) ถ้าไม่ใส่ เรื่องที่อัปเดตล่าสุดจะขึ้นก่อน |

**ไฟล์ตอน**

| ค่า | ความหมาย |
|---|---|
| `title` | ชื่อตอน |
| `date` | วันที่ลง รูปแบบ `ปี-เดือน-วัน` ใช้ได้ทั้ง ค.ศ. และ พ.ศ. |
| `label` | ใช้แทนคำว่า "ตอนที่ N" เช่น `บทที่ 1`, `บทนำ` หรือ `ตอนพิเศษ` (ตอนนี้จะไม่ถูกนับเลขตอนอัตโนมัติ) |
| `part` | ชื่อภาค เช่น `ภาคที่ 1 · The Past` สารบัญจะจัดกลุ่มตอนตามภาคให้ |
| `draft` | ใส่ `true` ถ้ายังไม่อยากให้ขึ้นเว็บ |

ไฟล์หรือโฟลเดอร์ที่ขึ้นต้นด้วย `_` เช่น `_โน้ตตัวละคร.md` จะไม่ขึ้นเว็บ ใช้จดโน้ตได้

> **ข้อควรรู้:** repo นี้เป็น public ทุกไฟล์ใน repo (รวมถึงตอนที่ตั้ง `draft` และไฟล์ `_โน้ต`) คนอื่นเปิดอ่านบน GitHub ได้ ถ้าต้องการเก็บร่างเป็นความลับ ให้เก็บไว้ที่อื่นก่อน หรือเปลี่ยน repo เป็น private แล้ว deploy ผ่าน Netlify แทน (GitHub Pages สำหรับ repo private ต้องใช้แพ็กเกจเสียเงิน)

## เปิดเว็บด้วย GitHub Pages (ทำครั้งเดียว)

1. ไปที่ **Settings → Pages** ของ repo ในส่วน Build and deployment เลือก Source เป็น **GitHub Actions**
2. Merge PR นี้เข้า `main` ระบบจะ build และ deploy ให้อัตโนมัติ (ดูสถานะได้ที่แท็บ Actions)
3. เว็บจะอยู่ที่ `https://janurok.github.io/<ชื่อ-repo>/`
4. แนะนำให้ใส่ URL นี้ในช่อง `url:` ของ `content/site.md` เพื่อให้เวลาแชร์ลิงก์ใน LINE หรือ Facebook มีพรีวิว

ถ้า deploy ครั้งแรกไม่ผ่านเพราะยังไม่ได้เปิด Pages ให้เปิดตามข้อ 1 แล้วกด **Re-run jobs** ในแท็บ Actions

ถ้าอยากใช้ Netlify แทน: ตั้ง build command เป็น `node scripts/build.mjs` และ publish directory เป็น `dist`

## ดูตัวอย่างบนเครื่องตัวเอง (ไม่บังคับ)

ต้องมี Node.js 18.17 ขึ้นไป

```
npm run dev
```

แล้วเปิด http://localhost:4321 แก้ไฟล์ใน `content/` แล้วรีเฟรชหน้าได้เลย

## ปรับหน้าตา

สีและฟอนต์ทั้งหมดอยู่ส่วนบนของ `theme/style.css` เช่น `--accent` คือสีหลัก (ปุ่ม ลิงก์) และ `--bg` คือสีพื้นหลัง แต่ละธีมมีชุดสีของตัวเองอยู่ถัดลงมา
